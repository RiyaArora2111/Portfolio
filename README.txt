RIYA ARORA PORTFOLIO

Files:
- index.html: portfolio content and structure
- styles.css: responsive warm charcoal/pink/beige design
- script.js: on-demand scroll-driven canvas animation, reduced-motion static frame, accessible mobile navigation, active section, and current year
- assets/animation/: the 50 supplied JPEG frames and frames.js manifest

To preview:
1. Extract the ZIP folder.
2. Open index.html in a modern browser. For best results, run a local server from this folder:
   python -m http.server 8080
3. Visit http://localhost:8080

Notes:
- Animation assets are included locally; no animation API or key is required.
- Animation frames load as needed with a small concurrency limit; reduced-motion mode loads only a static frame and disables the sticky scroll sequence.
- Google Fonts load from the internet; system font fallbacks are included.
- HydroLens is labelled as a prototype concept, not a validated product.
