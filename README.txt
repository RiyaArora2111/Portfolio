## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)
- Live Server extension (optional)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/RiyaArora2111/Portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Portfolio
   ```

3. Open the project in Visual Studio Code:

   ```bash
   code .
   ```

4. Open `index.html` in your browser or launch it using the Live Server extension.
